Connect the Android app

Choose a secure route, then copy its URL and the Link token into Secure Pocket on Android.

  1. Choose your connection:

    Recommended: Tailscale

    Install Tailscale on this computer and your phone. Sign in to the same tailnet on both.

    Background mode keeps Serve active after you close the terminal and resumes after a computer restart or Tailscale restart. Link and Tailscale must be running. To disable this route, run tailscale serve --bg 8732 off.

    Use a LAN HTTPS address instead, or add one as preferred

    Set up direct TLS or a trusted HTTPS proxy on this computer. The URL below is available when Link’s TLS or public HTTPS address is configured.

    If you set both URLs, the local HTTPS certificate must match the hostname in the Tailscale URL. Leave Local URL blank to use Tailscale alone.

  2. Copy the Link token:

    Keep this token private. It authenticates the phone to Link.

  3. On Android, open Settings → Library Location → Secure Pocket Link. For Tailscale only, leave Local URL (preferred) blank and paste the Tailscale URL into Tailscale URL (fallback). Paste the token, tap Test connection, then Save settings.
Use Docling from Android

Open Settings → Transcription → Docling formatting. Select Pre, Post, or Both, enter the Link HTTPS address under Local URL or Tailscale URL, and enter the same Link token. Allow sending audio or text to processing servers and tap Save settings.

Encryption key backup

Link uses this key to encrypt recordings and saved secrets. Download a recovery copy before moving Link or its library to another computer.

Key file: Loading…

Protect this file. Anyone with the key and encrypted library can read the recordings. Store the recovery copy separately on encrypted storage. Do not share it.

To restore on another computer: stop Link, restore this key and the matching config.json to Link’s settings folder, restore the library, then start Link. The Secure Pocket Link README has platform-specific settings-folder paths.

Backup destination

Recordings sent from your phone are saved in this folder. A mounted NAS folder works when it is mounted and writable before Link starts.

Use an absolute path. Link creates the folder if needed. For a NAS, enter its mounted path (for example /Volumes/Archive/Pocket on macOS, Z:\Pocket on Windows, or /mnt/nas/Pocket on Linux).

Change Link token

Link creates a private token on first launch. Keep it private.

If you save a new token, update the Link token in Android to reconnect.
