Secure Pocket

Link settings

Choose where this computer stores Pocket recordings, connect your phone on your local network, and check that the backup folder is ready.

Backup destination

Recordings sent from your phone are saved in this folder. A mounted NAS folder works when it is mounted and writable before Link starts.

Use an absolute path. Link creates the folder if needed. For a NAS, enter its mounted path (for example /Volumes/Archive/Pocket on macOS, Z:\Pocket on Windows, or /mnt/nas/Pocket on Linux).

Phone access token

This private token protects the library on your network. Enter the same token in the Secure Pocket app.

A token is created automatically on first launch. Keep it private. Saving a new token disconnects phones using the old one.

Document processing

Secure Pocket can send recordings and notes to your configured local Docling service for transcription or processing.

Leave empty to use the default service address for your installation. The Docling service address is used by Link, not by the phone.

Pair your phone

After saving, open Secure Pocket on the same Wi-Fi or tailnet as this computer.

  1. In Secure Pocket, open Settings → Library location → Secure Pocket Link.
  2. Enter Finding this computer’s address… and the token shown above.
  3. Tap Test connection. The connection should report that the library is ready.

If Link runs in Docker, use the host computer’s LAN IP or set LINK_PUBLIC_HOST. The settings page itself is private to this computer at http://127.0.0.1:8733.
