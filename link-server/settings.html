Connect the Android app

  1. Put your phone on the same Wi-Fi as this computer, or connect both to the same tailnet.
  2. In Secure Pocket on Android, open Settings → Library Location, select Secure Pocket Link, and enter these values:

  3. Tap Test connection. Once it succeeds, tap Save settings.
Use Docling from Android

Open Settings → Transcription → Docling formatting. Select Pre, Post, or Both, then enter the same URL in Secure Pocket Link URL with Docling enabled and the same Link token. Allow sending audio or text to processing servers and tap Save settings.

Backup destination

Recordings sent from your phone are saved in this folder. A mounted NAS folder works when it is mounted and writable before Link starts.

Use an absolute path. Link creates the folder if needed. For a NAS, enter its mounted path (for example /Volumes/Archive/Pocket on macOS, Z:\Pocket on Windows, or /mnt/nas/Pocket on Linux).

Change Link token

Link creates a private token on first launch. Keep it private.

If you save a new token, update the Link token in Android to reconnect.
